# 第一幕「参道」3D 资产

2026-09-30。供独立 Godot 预览使用的可编辑场景试样，未替换正式 v3 探索背景或主入口。

## 文件

- `act01_approach.glb`：游戏导入文件，真实可旋转几何、PBR 材质与全部纹理内嵌
- `source/act01_approach.blend`：Blender 4.3.2 编辑源，含分组网格、原始打包纹理、仅用于美术预览的灯光与双机位
- `source/preview/`：Blender 固定构图、斜侧检查、独立 GLB 回导渲染；不等同于引擎截图
- `source/verification.json`：独立回导的实测统计
- `source/.gdignore`：阻止 Godot 重复导入 `.blend`、源渲染与验收记录

## 美术与来源

已实际目检仓库 `assets/bg/approach/l2_test.png` 和用户上传的回廊源场景渲染。沿用暖旧木、和纸、黛青石瓦、金色灯火与幽玄神社氛围，重新构成第一幕左侧平地、右侧上升台阶的横向空间。

用户上传的 `Omagatoki_Corridor.blend` 提供五张打包纹理（木、石、瓦、和纸、灰泥），以及水钵、石灯笼、注连绳/纸垂的原始几何。鸟居、坡地、石阶、边界石、片簇树冠、小社与散落植物重新搭建，没有移植第二幕完整回廊。树冠使用原和纸纹理乘暗绿/靛青颜色，连续坡地使用原石纹理乘靛灰颜色；均已验证导出为标准 glTF 纹理与颜色因子。

当前为风格化立体试样，仍有可见多边形切面；没有宣称与二维水彩成品完全一致。未增加角色模型、碰撞、导航、正式交互、破坏状态或战斗规则。

## 实测预算

- 67 个逻辑网格对象，129,038 三角面，27 个使用中的材质
- 5 张内嵌图片：和纸 1024×1024，其余各 768×768
- GLB：10,919,888 字节；1 个内嵌二进制 buffer，0 外部资源依赖
- GLB 不含相机或灯光；源文件保留专用预览灯光组
- 五个空节点作为 Godot 中的光照/线索锚点，随 GLB 导出
