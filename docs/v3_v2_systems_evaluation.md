# 当前系统保留与改造决策

> 更新：2026-09-30。按 GDD v4 修订；[2026-09-29 原评估](archive/2026-09-30-before-v4/docs/v3_v2_systems_evaluation.md)完整归档。

保留原评估中“不整体移植旧战棋系统”的结论；撤销已经过期的未接线清单和“单场单敌”等描述。默认运行的 v3 已有多敌 HP、执念、倾覆、免疫与高压相关代码，但仍存在波级共享状态等原型限制。

| 系统 | 决策 | 当前边界 |
|---|---|---|
| 旧网格／寻路／移动 AP／方向修正 | 不进入新版战斗 | 原文件保留供旧版本复现 |
| 旧噪音 BFS 与巡逻搜索 AI | 不移植 | 保留铃声与控制的表现和玩法价值 |
| 场景槽与邻接连锁 | 保留并规范 | 后续明确合法对象、传播时机和预览 |
| 灵气、破阵、封印、执念 | 保留 | 阈值按遭遇配置，不硬塞给所有案件 |
| 抽弃牌、费用、留牌补满 | 保留 | 在其上增加收藏、可编辑构筑、整理和成长 |
| 多敌单位 | 保留 | HP 已独立；意图与状态要逐步独立化 |
| 回合编排 | 复用并拆清职责 | 支持战斗和仪式两种目标，避免两个重复引擎 |
| v2 NarrativeState | 核验后复用 | 不能因注册 autoload 就视为 v3 已完成存档闭环 |
| 2.5D 探索与 UI | 保留 | 现有画面与素材不因 GDD 改写而替换 |

新的护盾、标记、主战／支援、牌组编辑与仪式目标均属设计项。具体分期见 [代码实施方案](代码实施方案.md)，实装事实见 [进度](进度.md)。
