# UI 素材任务入口

> 更新：2026-09-30。旧 23 项任务已退出当前执行清单。

[原任务清单](archive/2026-09-30-before-v4/docs/Codex_UI_Generation_Task.md)及旧数据保留用于追溯；不得据此批量覆盖当前素材。

当前任务以 [GDD](GDD.md) 和 [美术规范](Art_Bible.md) 为准。新增构筑、道具栏、手记等先复用和纸面板、卡框、图标与字体；只有复用确实不能满足表达时才立新的素材任务。

每个新任务至少记录：所属功能、视觉参考、尺寸与透明要求、输出路径、使用场景、状态差分、验收方式。功能尚未进入实施时，不为预计用到的界面先批量生成图片。

本次没有下达新的图片生成任务，现有卡面和 UI 保持不变。
