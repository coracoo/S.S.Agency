## 冲突处理

用户最新决策优先。产品目标以 GDD v4 为准，美术以当前实装和 Art_Bible 为准，已完成状态以代码与验证记录为准。历史文档的“必须”“唯一规范”“全部沿用”等语句不再约束当前版本。

现有脚本注释中沿用的 GDD 节号属于 v3 文档，可在归档查找；本次未为重新编号而批量修改代码注释。

v4 仅指设计文档版本；本次没有创建另一套游戏代码，也没有改动 v3 默认入口。最近一周事实主要集中在 2026-09-29；不能把旧文档修改时间当成全部内容发生时间，或把“本轮”记录拆成虚构日期。
