# 《逢魔退治帖》美术与视听基准 v4

> 更新：2026-09-30。保持最近一周已实装的日式水彩绘本与伪 2.5D 横屏风格。
> 旧港式／蒸汽朋克稿见 [历史原文](archive/2026-09-30-before-v4/docs/Art_Bible.md)，不再约束新素材。

## 一、优先级

用户最新反馈 → 当前三幕与角色的实际成品 → [绘本参考图](reference/style_ref_storybook_rpg.png) → 本文。玩法转向深度卡牌不触发美术换皮。

保留现有角色、参道／回廊／本殿、卡面、半身立绘、和纸面板和法术效果。新内容先复用，再按明确缺口补图；不按旧清单全量重生成。

## 二、画面语言

完整水彩背景、纸质肌理、柔光、暖赭和纸白、黛青夜色，朱砂与哑光金作为小面积强调。保持日式民俗器物与幽玄气氛，道家与阴阳术主题通过故事和术法自洽表达。

避免瓦片拼接感、像素小人比例、赛璐璐硬描边、西式宝石奇幻、霓虹赛博及蒸汽齿轮换皮。现有素材不因文档更新被删除。

## 三、伪 2.5D

- 保留前景视差、中景遮挡、完整背景、角色接触阴影和落脚遮罩。
- 人物大小、脚点、透视按场景配置与近期成品校准，不使用所有人占屏 40%—45% 的统一硬比例。
- 行走遮罩表示角色脚底可行路径，遮挡表示深度；不推导战斗射程、换线 AP 或棋盘碰撞。
- 前景不能长期挡住交互热区；重要线索锚在器物位置，必要时有轮廓和文字提示。
- 保持背景过填充以防镜头偏移露边，新素材需在实际镜头边界检查。

保留底部扇形手牌、卡牌详情、和纸对话、姓名签、左右半身立绘、说话者提亮。新增构筑、牌堆浏览、手记和道具栏沿用同一材质。战斗信息可以比探索更密集，不通过隐藏费用、阈值或免疫来追求留白。

九图边距需要可追踪的配置；当前 `theme.gd` 仍有 108px 常量，这是实现事实，不能宣称已全部外置，也不在此次文档任务里改代码。

## 五、角色与动画

优先复用 `assets/chars/` 的现有立绘和动作。追加帧需保持轮廓、身高、脚区锚点和透明边缘一致；检查施法伸出部位、武器、纸人飘带是否切格或横跳。

待机节奏、施术速度和移动透视以近期用户调整为准，不因旧规格要求更多帧而盲目重制。对话面板、文字和选项须盖住立绘，不被人物遮挡。

## 六、音乐与文本协作

为每案规划调查、紧张、真相、余波的主题联系；同一旋律可通过不同配器表达变化。保留风、水、纸响、铃声等环境和现有音效。完整 BGM 编排与混音是制作目标，不是现有完成状态。

重要声音线索配字幕或视觉提示；对话可回看，提示可主动打开。演出应支持加速和降低震屏／闪光。美术负责传递线索与情绪，不承担“所有信息只能画出来”的限制。

## 七、导入与验收

先检查原始素材，再在探索、战斗、对话实际尺寸下目检；确认透明边缘、脚点、遮挡、牌面文字、热区和背景边界。新增 PNG 通过 Godot 导入，导出包内读取遵循现有 `PngLoader` 的资源访问方式，不用系统文件路径假定 PCK 中存在原文件。

每次新增素材记录用途、路径、参考来源、配置入口和验收图。本轮无新图生成或现有图替换。
