## 本地帧采集

使用已有Godot4.7.2从项目默认入口运行，或通过GODOT_BIN指定本地引擎。Windows启动器为`play.bat`/`启动游戏.bat`。

隔离采集入口：

```sh
python tools/campaign/run_act_one_checks.py --graphical --script res://tools/campaign/capture_act_one_walk.gd --output-dir <仓库外证据目录>
```

设置`ACT_ONE_FULL_ROUTE=1`采完整20点。目录中的`walk_frames/frame_*.jpg`保留按序帧，`walk-report.json`保留真实时间、坐标与抵达结果，可取第一帧/最后一帧并生成视频。单独界面：`capture_ui_polish.gd`；定点全场景：`capture_atmosphere_review.gd`配合`ATMOSPHERE_ALL_REGIONS=1`。

所有采集先核验临时user目录，不碰正式玩家存档。仓库不提交截图、视频、Godot工具二进制或导入缓存。
