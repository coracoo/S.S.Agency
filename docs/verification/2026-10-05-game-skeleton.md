# 2026-10-05 大地图与UI骨架整合

用户负责角色精灵动作帧，本轮仅整理地图呈现、战斗舞台、UI输入和既有流程。开发分支 `feat/game-skeleton-integration` 从已发布 `7ca44ba` 开始；未改角色PNG、atlas、帧manifest、身高或战斗数值。

## 已实现

- 正式战斗使用独立 `SubViewport` / `World3D`，复用 `act_one_geometry.gd` 的真实寺域、灯光、材质和道具。按战前所在地区选择安全战斗构图，不按夜次错误套用静态插画。探索返场仍用原检查点坐标；战斗镜头锚点不写入存档。
- 友方现有动画帧和敌方现有动作反馈桥接到受光 `Sprite3D`。原人物脚锚、物理身高和屏幕技能热区保留；不生成新动画。接触影使用真实shader参数 `opacity`，月光薄片投影参与地面遮挡。
- 景深以相机视轴距离划分近中远。人物全身与2.2米交互邻域保持焦内，远NPC正常失焦。单pass十三点错位采样替代九点规则核，减轻木板/石栏重影。旧试点世界Z模式仍可独立运行。
- 景深开关在本次会话内跨战斗、跨舞台保留，不写入剧情存档；退出会话后按默认开启。
- 两株前景杉树移到通路外侧，避免遮清明；枯根尖按实际地表三角形落地。碰撞与可走路线未新增障碍。战斗树木遮挡对所有身体做投影OR判断，每帧只渐隐一次，不会只保护画面中心而吞掉左侧敌人。
- 探索只常驻地图和暂停入口，移动教学渐隐；景深、编队、存档和返回标题在暂停内可达。对白/其他操作期间整层探索HUD退场。
- 战斗空状态不占卡片高度，技能名称与费用横排，选中才展开详情；取消整幅空底台。道具、日志和返回确认具有鼠标遮罩、键盘焦点圈、Esc关闭与原焦点恢复。

## 实拍复现

前庭/回廊的探索、景深开关、战斗、合法技能目标、道具及日志模态：

```sh
python tools/campaign/run_act_one_checks.py --godot <Godot4.7.2路径> --graphical --script res://tools/campaign/capture_battle_world.gd --output-dir <仓库外目录>
```

设置 `BATTLE_WORLD_ALL_REGIONS=1` 额外采集参道、纸棺庭、镜殿、本殿、中庭与两侧径。`BATTLE_WORLD_REGION_ONLY` 可用逗号选择已登记地区。输出PNG及 `capture-report.json`。这些定点通过合法restore_world构图，不声称由玩家步行完成。

连续行走沿用 `capture_act_one_walk.gd`；`ACT_ONE_FULL_ROUTE=1` 采20个路线点，输出 `walk_frames/frame_*.jpg` 与真实时间报告。固定30Hz离线短片仍用 `capture_atmosphere_video.gd` 并向引擎传 `--fixed-fps 30`，不能当目标电脑实时帧率。

北侧径上缘的旧杉木根仍有偏悬的视觉观感；本轮按实际土坡修了三株枯树，没有重做全林模型。

- 角色方向与新动作由用户制作，本轮保留现有帧契约，没有虚称新增上下或斜向帧。
- 保留原剧情、五夜状态、奖励与存档schema。没有新增剧情、经济、战斗规则或传送菜单。
