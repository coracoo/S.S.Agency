# 六个实地机关与分段演出验证

日期：2026-10-08。Godot 4.7.2 / Compatibility / Windows。当前完整持续目标尚未完成。

## 实际接入

六模块为C2水口、C3/C6共享修渡、C6双线拆接、换手停阵、漂木担架和后巷镜路。`saga_stage.gd`按批准`source_index`切分opening/choice/aftermath，在叙述操作成功之前回到地图；通道末尾和不在lines中的动作来源块也能阻止继续。

角色走到物件旁按E操作，每次确认只提交一步。空船去回有连续Tween和镜头跟随，动画期间锁输入；换手须切到另一角色，焰华换形态不算换人。漂木本体阻挡中央路线，两侧仍可接近支点；清走后解除碰撞并将木料移到路线之外，担架需经过三个实际位置。后巷必须先遮近镜，再完成原短战，胜利后才拆远镜和引导接应。

操作只写物理状态与位置证据，不发装备、不恢复资源、不直接改剧情flags。水口的钟音来自镜边异响，按批准原文保留“钟绳仍捆着”的事实，没有新增一只正在摇响的实体钟。已修渡的场次隐藏无效修渡操作点；可见结构仍留在现场。

## 保存与兼容

当前schema3/progression_version=3要求`mechanisms={version:1,legacy:{events,battles},states,history}`。历史含动作、操作者、场次/选择、坐标、事件/战斗前缀；后巷战后动作还指向真实胜利ID。严格重放拒绝未来战果补填、错序、远程操作和损坏类型。

旧schema2或无等级v1/v2先完整校验和原字节备份，才升级当前版本；不重算已有无等级角色，不重发钱或物品，不重置商人库存。历史完成只按原事实投影，标记迁移前缀而不虚构操作日志；暂缓B不冒充修路/救人成功。新局不能自行伪造历史前缀，新版本缺状态拒绝静默补造。
