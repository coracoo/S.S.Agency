# 封灵事务所 (S.S.Agency) — 画面风格问题诊断报告

> 对比基准：
> - **当前画面**：`tmp_current_ui.png`（游戏实际运行截图）
> - **目标参考**：`template.png`（基于 GDD 的 UI 设计参考图）
> - **设计规范**：`S.S.Agency/UI.md` + `UI-Godot-Reference.md`
> - **GDD**：`docs/GDD.md`
> - **代码实现**：`scripts/scenes/battle_scene.gd`

---

## 一、总体评估

当前游戏画面与 GDD 目标存在**显著差距**，主要体现在：

1. **UI 布局与规范严重不符** — 角色面板、技能栏、队伍栏的尺寸、位置、结构均与规范差距较大
2. **UI 美术风格主题错位** — AI 生成的 UI 素材（边框、按钮、图标）走**西幻/魔兽风格**（蓝绿宝石+华丽金边），与游戏**港式民俗/中式灵异**主题冲突
3. **角色与敌人精灵图质量两极分化** — 玩家角色和主要敌人精美，但 shadow 系列占位图质量极差，且渲染比例偏大
4. **地图背景与网格透视不匹配** — 背景图是固定视角概念图，与等距网格叠加存在错位感
5. **效果层过于简陋** — 火焰、水波、糯米等核心玩法效果仅用代码多边形绘制，无动画 sprite
6. **缺少关键功能视觉化** — 恐惧值、灵气密度、环境互动按钮、敌方意图图标等均未实现

## 三、UI 美术风格问题（严重）

### 3.1 生成素材主题错位

当前 `assets/ui/generated/` 下的所有 UI 素材均为 **AI 生成的西幻/魔兽风格**，与游戏主题严重冲突：

| 素材 | 当前风格 | 目标风格 | 问题 |
|------|----------|----------|------|
| `ui_bottom_hand_panel.png` | 暗金+蓝绿宝石+卷草纹 | 玄黑+暗金+朱红，中式云纹或符纸纹理 | 🔴 主题错位 |
| `ui_card_frame.png` | 华丽金边+蓝色菱形宝石 | 深褐符纸边缘+细金线+中式回纹 | 🔴 主题错位 |
| `ui_status_panel.png` | 同上 | 玄黑底+金色卷轴边框 | 🔴 主题错位 |
| `ui_diamond_button.png` | 蓝绿宝石+金边菱形 | 暗金+靛青，中式菱形窗格 | 🔴 主题错位 |
| `skill_icon_fire.png` | 西方火焰莲花+魔法阵 | 三昧真火/符咒火焰，中式火焰纹 | 🔴 主题错位 |
| `skill_icon_slash.png` | 西方剑刃+蓝光 | 桃木剑/铜钱剑，中式斩击 | 🔴 主题错位 |
| `skill_icon_soul.png` | 西方骷髅+灵魂 | 钟馗判官笔/勾魂锁 | 🔴 主题错位 |
| `skill_icon_talisman.png` | 西方魔法卷轴 | 黄符纸+朱砂符文 | 🔴 主题错位 |

**核心问题**：生成 prompt 中缺少"中式灵异/港式民俗/风水符咒"等关键词约束，导致风格偏向西幻 MMORPG。

### 3.2 九图切分使用不当

当前代码中虽然加载了生成的 UI 纹理，但 `UI_PATCH_MARGINS` 是手动估算的：

```gdscript
const UI_PATCH_MARGINS := {
    "bottom_hand": Vector4i(100, 78, 100, 78),
    "status_panel": Vector4i(58, 88, 58, 88),
    ...
}
```

**问题**：
- 未通过 `tools/slice_ui_atlas.py` 自动切分，边距可能不准确
- `ui_frame_atlas_source.png` 和 `skill_icon_atlas_source.png` 是 1254×1254 的大图，但没有被代码加载使用
- 生成的独立图标（skill_icon_*.png）尺寸不统一（248×355 ~ 286×355），直接拉伸到 70×70 会变形

### 4.3 头像裁剪问题

代码中头像裁剪逻辑：
```gdscript
if portrait_crop:
    atlas.region = Rect2(frame_w * 0.22, frame_h * 0.04, frame_w * 0.56, frame_h * 0.58)
```

**问题**：
- 从 64×64 的 sprite 帧中裁剪出约 36×37 的区域作为头像，分辨率极低
- 在 166×188 的面板中拉伸显示，**严重模糊**
- `template.png` 中的头像是**独立绘制的高精度半身像**，而非 sprite 裁剪

## 五、地图、网格与地形问题

### 5.1 背景图与网格透视冲突

| 项目 | 规范/参考 | 当前实现 | 问题 |
|------|-----------|----------|------|
| 背景 | `兰寺.png` 暗化 38% 作为氛围背景 | `temple_courtyard_bg.png` 或 `兰寺.png` | 🟢 基本正确 |
| 叠加方式 | 网格半透明，保留等距轮廓 | 当使用 courtyard 背景时，网格只画半透明覆盖+线框 | 🟡 可读性下降 |
| 透视匹配 | 背景与网格等距透视一致 | `temple_courtyard_bg.png` 是等距渲染，但格子尺寸 128×64 与背景不完全匹配 | 🟡 轻微错位感 |

**具体问题**：
- `temple_courtyard_bg.png` 本身是精美的等距庭院场景，但地图网格叠加在上面时，**地面的八卦阵、火盆、水坑等装饰与游戏逻辑格子不对应**，造成"场景暗示了可互动物体但实际上没有"的困惑
- 当 `using_painted_map = true` 时，普通地形（stone/wood/grass）完全不显示覆盖层，只有特殊地形（wall/water/oil 等）才画线框，导致**大量空白格子没有任何边界标识**，可读性差

### 5.2 地形瓦片问题

| 地形 | 规范颜色 | 当前实现 | 问题 |
|------|----------|----------|------|
| 油地 | 暗黄 `#8B7355`，微光泽 | `oil_dark.png` + 代码暗色覆盖 | 🟡 基本可用 |
| 水面 | 青蓝 `#4488AA`，波纹动画 | `water_blue.png` + 代码波纹 | 🟡 基本可用 |
| 火焰 | 橙红 `#FF6622`，闪烁动画 | 代码多边形闪烁 | 🔴 无 sprite 动画 |
| 糯米 | 米白 `#F5F5DC`，散落颗粒 | 代码小圆点 | 🟡 过于简陋 |
| 墨线 | 纯黑 `#000000`，连线+发光 | 无 | 🔴 完全缺失 |
| 符纸 | 金黄 `#FFD700`，浮动动画 | 代码多边形（黄色纸片） | 🟡 无浮动动画 |
| 灵气 | 紫黑 `#6B2FA0`，雾气效果 | 无 | 🔴 完全缺失 |

**v2 瓦片集问题**：
- v2 瓦片是 `256 × 512` 的 4 帧竖排，但代码中 `_load_v2_frame_texture` 只取了**上半部分**（第一帧）：
  ```gdscript
  atlas.region = Rect2(0, 0, base.get_width(), minf(base.get_height(), base.get_width() * 0.5))
  ```
- 这意味着**4 帧动画完全没被使用**，所有地形都是静态第一帧
- `floor_stone_tile.png` 等 v2 瓦片风格是**简约等距几何体**，与角色像素风差异较大

### 5.3 网格高亮规范不符

| 类型 | 规范 | 当前实现 | 问题 |
|------|------|----------|------|
| 可走区域 | 蓝青色石板原色 | 依赖背景图或瓦片原色 | 🟢 正确 |
| 当前选中格 | `#50ff78` 25% + 绿色发光边框 + 外发光 | `Color(1, 1, 1, 0.25)` 白色覆盖 | 🔴 颜色/效果不符 |
| 可移动范围 | `#60a0ff` 20% 淡蓝 | `Color(0.1, 0.8, 0.3, 0.4)` 绿色 | 🔴 颜色不符 |
| 敌方攻击范围 | `#ff6060` 25% + 微弱脉冲 | `Color(1, 0.2, 0.2, 0.5)` 红色 | 🟡 接近但无脉冲 |
| 技能作用范围 | `#c060ff` 20% 紫色 | 未明确区分 | 🟡 缺失 |
| 危险/陷阱 | `#803030` 40% 暗红 | `Color(1.0, 0.24, 0.12, 0.52)` 线框 | 🟡 表现形式不同 |

## 七、动画与特效问题

### 7.1 角色动画

| 动画 | 规范 | 当前实现 | 问题 |
|------|------|----------|------|
| Idle | 4方向，6fps，循环 | 4方向，4fps，循环 | 🟡 略慢 |
| 行走 | 行走精灵表或 idle 加速+弹跳 | **瞬移**，无位置 tween | 🔴 无移动动画 |
| 受击 | 白色闪烁 100ms + 红色粒子溅出 | 无 | 🔴 完全缺失 |
| 死亡 | alpha渐变 + 向下飘落/燃烧灰烬 | 无（直接移除 sprite） | 🔴 完全缺失 |
| 朝向切换 | 根据目标方向更新 facing | 有 facing 字段，但切换生硬 | 🟡 无过渡 |

### 7.2 环境特效

| 特效 | 规范 | 当前实现 | 问题 |
|------|------|----------|------|
| 火焰点燃 | 粒子爆发 + 屏幕微震 | 无 | 🔴 缺失 |
| 火焰蔓延 | 火焰 sprite 从旧格 tween 到新格（0.3s） | 瞬间切换 + 代码多边形闪烁 | 🔴 无蔓延动画 |
| 水缸推倒 | 水粒子向四周爆发 + 水渍 alpha 0→1 | 代码水波同心圆 | 🟡 过于简陋 |
| 爆燃 | 大粒子爆发 + 冲击波圆环 + 屏幕震动 | 无 | 🔴 缺失 |
| 敲铃铛 | 金色音波圆环从铃铛向外扩散（3个同心圆） | 噪音波纹：菱形线条扩散 | 🟡 表现形式不同 |

| 推/拉物体 | 物体 sprite tween 0.2s + 到达微弹 | 瞬间切换位置 | 🔴 无动画 |

### 7.3 噪音可视化

当前噪音波纹使用**菱形线条**（`draw_polyline`）：
```gdscript
_overlay_layer.draw_polyline(ring, Color(1.0, 0.75, 0.2, alpha), 3.0)
```

**问题**：
- 规范要求是**同心圆环**扩散，当前是菱形，形状不符
- 只有单层线条，规范要求**3个同心圆，alpha 递减**
- 缺少音波从声源向外扩散的动画感
