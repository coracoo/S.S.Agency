## Phase 1: 地形系统 ✅ 85%

### 已完成

- **data/terrains.json** — 15种地形，tag系统完善
  - 基础: stone, wood, sand, wall, water
  - 可燃: oil, grass, forest, bush
  - 功能: rice, seal, curse, elevated
  - 危险: trap, void
  - 每种地形含 tags、move_cost、color、可选 dodge

- **data/effects.json** — 7种效果
  - fire: duration=2, damage=4, spread_per_turn=1, spread_tags=["solid"]
  - water_spread: duration=5, spread=true
  - rice: duration=99
  - ink_line: duration=99, block_spirit=true
  - talisman: duration=99
  - curse_zone: duration=5, damage=2
  - explosion: duration=1, damage=8

- **data/objects.json** — 7种物体
  - brazier: pushable, 可点燃
  - water_barrel: pushable, 可推倒(water_spread)
  - rice_bag: pushable, 可推倒(rice)
  - bell: 不可推, 可敲(ring, noise_volume=4)
  - door: 不可推, 可开关(open/close)
  - coffin: 不可推, boss容器
  - explosive_barrel: pushable, 可点燃, 标签含 explosive

- **data/rules.json** — 6条交互规则
  - fire_ignite_flammable: 火+可燃→着火
  - fire_extinguish_water: 火+水→灭火
  - water_wets_flammable: 水+可燃→去可燃标签
  - fire_oil_explosion: 火+油→爆燃
  - fire_explosive_barrel: 火+爆炸物→移除物体+爆炸+向邻居蔓延火
  - burning_damage_unit: 火+单位→伤害

- **game_map.gd** — 多层地图数据结构
  - Ground/Effect/Object/Collision 四层
  - v1/v2 格式兼容
  - `get_tags()` 聚合查询（地形+效果+物体+已移除标签）
  - `has_tag()` 快速查询
  - `add_effect()`/`remove_effect()` 效果管理
  - `tick_effects()` 效果持续计时
  - `remove_tag()` 标签移除机制
  - `_derive_collision()` 自动从地形标签推导碰撞
  - `_occupants` 字典管理单位占用

- **terrain_system.gd** — 交互规则引擎
  - 加载 rules.json，按标签匹配触发
  - 支持 result 类型: add_effect, add_effect_neighbors, remove_effect, remove_tag, remove_object, damage_unit, emit_event
  - `process_spread()` 每回合效果蔓延
  - 事件监听: effect:added, object:pushed_over
  - 防重入 `_processing` 标志

- **interaction_system.gd** — 环境互动
  - `push(unit, direction)` — 推物体1格，消耗1AP，发射 object:pushed
  - `push_over(unit, target_pos)` — 推倒容器，消耗1AP，发射 object:pushed_over
  - `interact(unit, target_pos, action)` — ring/open/close/ignite，消耗1AP
  - `can_reach()` — 曼哈顿距离==1检查

- **maps.json** — v2 多层格式
  - 地图ID: "paper_coffin_demo"（纸人抬棺）
  - 14×10 网格
  - 地形含 stone/oil/wood/water/rice/seal/curse/trap/void
  - 物体: coffin 在 [4,4]
  - 出生点: dict格式含 enemy templates (paper_effigy×3, water_ghost, jiangshi, red_lady, coffin_lord)

- **battle_scene.gd 地形渲染**
  - 地形颜色/纹理映射 (tile_top/tile_left/tile_right)
  - 效果层动画: 火焰闪烁、爆炸闪光、水波纹、陷阱脉冲、诅咒紫光、封印红边
  - 物体渲染: 纹理贴图 + 彩色底座环 + 中文标签
  - Kenney 等距瓦片素材集成
