# 动画帧本地遮罩批处理实施计划

> **For agentic workers:** 使用 superpowers:executing-plans 在当前任务逐项执行；不新建并行代理。用户已明确选择沿用已认可的本地遮罩流程。

**Goal:** 按用户最新澄清，处理在用动画帧中尚未处理好的异常底色残留，尤其已目检确认的清明跑步、苏合跑步、岑照跳跃、凛音跑步；立绘不处理。

**Architecture:** 只读正式七形态video_actions清单和其精确图集区域，建立全覆盖输入清单及原始hash。沿用本机CPU的SAM2主体分割、ViTMatte边缘细化、必要局部区域修正，先检查代表帧再批量处理动作。结果保存在独立build目录，旧图集、立绘及已认可的岑照白底试作保留。

**Tech Stack:** 现有Python环境、PyTorch CPU、SAM2.1 Tiny、ViTMatte Small、Pillow/NumPy/SciPy、FFmpeg。

**Spec:** 用户2026-10-08最新澄清：“先处理动画帧，尤其是你刚才评估有异常底色遗留的。立绘不需要处理”；已认可方法见`docs/characters/2026-10-08-guard-local-mask.md`。

## 约束与完成证据

- 静态立绘、NPC、敌人静态PNG不处理。正式动画单帧兼容姿势仅盘点，归入保留类，除非有明确动画修复需要。
- 不覆盖用户/其他任务的dirty文件，不删除原图、历史版本或untracked目录，不读取`.workbuddy`和人物参考目录。
- 不改变原帧数、名称、动作时长、画布、region、offset及脚锚；输出独立候选和可追溯映射。
- 用户停止游戏测试的指令继续有效；本轮仅执行用户授权的素材推理、像素核对及画面对照，不运行Godot/存档/单元测试。
- 颜色指标仅排序，不以“有绿色”判为错误。保护薄荷灰绿头发、清明绿发绿衣、苏合绿裤、双剑细刃和持有物。
- 无法恢复的源RGB污染不得冒充已修复；处理后更差的候选必须保留原帧为建议版本并写明原因。
- 结束前逐动作记录处理、保留或待解决状态；全覆盖不能由几张代表帧代替。
