## 1. 意图、来源和不可变边界

用户希望七章不再重复“走到标记—读对白—进战斗”，而是有剧情起伏、地图解谜、可读的战术与不同敌人的特殊掉落；新增神秘商人，使探索和构筑相互关联。用户已确认无人物等级，装备/道具/技能卡改变属性，技能卡跨职业但受武器与容量约束，速度决定战斗顺序。

本文选择“批准剧情保持原意，场景操作兑现已写明的行动，战果带来有限的新选择”。不新增章节、不重写 137 场批准对白、不把救人变成花钱购买资格。任何新说明使用机关标签、物品描述和独立服务文字，不改原角色台词，也不为商人补写未经批准的隐藏身份或主谋关系。

## 2. 基线缺口与实施选择

后六章已有独立地图，但 `scripts/campaign/saga_stage.gd:117` 把场次挂在地点锚点，主要交互仍是进入场次。`scripts/campaign/saga_world.gd:33`、`:67` 已有各章锚点和路网；可在既有地区内布置操作对象，不必扩展大世界或依赖新场景美术。

`data/rpg/saga_encounters.json` 在研究基线共 26 遭遇，没有 `loot` 字段；15 类敌人的差异主要在攻击和 Boss 机制。现行商店只卖恢复药、法力药、复苏药，价格为 18/22/45 银钱，初始后章银钱 120；胜利银钱按 `25 + xp / 5` 计算，没有逐商店库存。来源：`saga_catalog.gd:9`、`:46`，`saga_progress.gd:156`、`:170`，`saga_save_rules.gd:109`。

三个方向的取舍：全面重建七章会使批准剧情与迁移成本失控；只给每个标记加一道按钮不能形成变化；推荐分阶段加入 **地图上的局部可逆操作 → 小段真实世界验证 → 必要战斗 → 责任交接与余波**。先做可独立验证的机关和掉落账本，再做商人，不以任务系统或大规模美术补充为前置。

|---|---|---|---|---|
| 一·棺女 | 山路缓行与异象 → 守灯学习 → 队列压迫 → 镜中私人线索 → 结案留白 | 在水钵/灯/纸棺附近增加可察看的状态；第二夜保留辨认、安放、引路三步。每夜对象变化可见，避免同样标记重新亮起而场景不变 | 先读单体意图，再引入防护、打断与目标选择。沿用五场已登记遭遇和战前位置返场 | 原送行/镇守均保留。新增敌物不能代替旧物、顾氏小夜身份或结案选择；不在告别台词上叠商店和奖励动画 |
| 二·无眠街 | 日常错位 → 接人清路 → 旧灯实验 → 少吃半块饼的停顿 → 借声客 → 六碗热面 | 茶棚安全夹具：固定灯架/清出口后取芯；水口隔断开/关可反复操作，字幕与声纹同步；灯芯取走后局部路通、沟底余声仍在 | 借声客回放上一轮末次类别；地图试验先教“重复有来源”，战斗转成“主动控制它会重复什么”。C2-08 留无战斗喘息 | C2-13 原件引向西仓；物证必须等战后原场提交。神秘商人首见在危机解除后的安全路边，不截断热面与寄信 |

| 五·借命灯 | 患者具体处境 → 单床小试 → 维护册真相 → 明确取舍 → 两种压力节奏 → 床边逐人确认 | 以可见接头区分照明、吸梦和离去路；预览断开影响，托住后才能拆接；药库路线保留物件搬运/配对间歇，后院进行撤防复测 | 稳灯路线保留药库＋静室连续压力；隔离路线少一战但两人待醒。百手灯母的灯印—吸取—散罩与保护/打断相连，不靠敌方血量膨胀 | 不把醒来写成治愈。C5-15 分段草案引用两处实验证据；家属救援不作为隐藏药械购买条件 |
| 六·百夜无更 | 山上旧案回收 → 断干线 → 证明能停阵 → 巡守反扑 → 地面多处补办 → 最后清单 | 托杆、隔离、取销、另点照路灯；停阵换手复验外圈仍通。码头“系上层—垫支点—切右侧—移木—担架试走”；后巷“遮近镜—拆远镜—护出口” | 无更巡守左右锁片与胸牌回补是主战；其余为按原批准支线的必要遭遇。中央接应处可自由补給/休整，不借新的随机遭遇惩罚补救 | `dream_intake_stopped` 不等于 `clinic_awake`。后巷出巷不等于过河。已送行不再遇见小夜；镇守可补原迟送行；真实回执才结清 |
| 七·天明之前 | 入厅诱惑 → 两阶段实战 → 胜利未解决牵连 → 沉静核证与选择 → 所选第三阶段 → 后日谈 | 决策窗口能查看真实地面清单和可选刻名板；三处锚点显示出口→中段→内圈依赖；只表达已知方案，不新增强制大谜题 | 保留护面、执灯人、第三阶段的资源承接与失败短聊。已赢阶段不重复发奖励；不在第二阶段后刷商店无条件洗满资源 | 四方案及其二次确认完整保留。旧名来源不明可以留白；收全掉落/购买神秘物品/高评分都不能代替五项撤阵条件 |

普通段落目标为每两次高压力段之间至少一次可自由观察、整备或人物余波。关键段可连续高压，但事前标明退出点与资源承接。每章新增一种核心地图规则，后章组合而非逐章再教同一种“点三盏灯”。时间预算以小型地图操作 1—3 分钟、完整机关 3—6 分钟为初始目标，需真人试玩调整，不能当成已测时长。

## 4. 可先实施的地图机关契约

首批选 C2 水口、C3 修渡、C6 双线与后巷；它们的因果、复测和可补做路径已在批准对白写明。新增配置登记机关 ID、章节/地点、前置场次、有限局部状态、允许命令、状态反馈、可重置点与对应剧情动作。地图视图请求命令，由会话在候选存档上验证，场景不直接发奖或跨章。

局部错误只提示冲突、阻止危险提交或恢复未提交布置；不擅自新增死人、坏结局和不可逆损失。已经提交的道路开放不随离章/休息重置。机关状态另设版本化扩展，不能塞入严格重放的 `world.event_flags`；`saga_save_rules.gd:40` 起按原事件比对世界镜像，直接添加任意机关 flag 会破坏合法档。新扩展要与根校验、历史镜像、迁移和隔离测试同时接入。

## 5. 神秘商人：银钱、库存与出现时机（新增设计）

“神秘商人”是独立新服务角色的显示名，不指定真实身份、组织和秘密知识。只售可选退魔用品与装备；交易说明从物品功能出发，不声称知道沈烛舟的全部真相。首版可用现有中性柜台/包裹物件承载服务，独立静态美术后续补齐，不复用并改写陶婶、乔伯或许照漪的身份。

只使用已有银钱，不增加第二种可购买货币，不收剧情物证、患者物品、回执、魂或控制实销。特殊掉落中的证据条目不可卖；装备入库存后走统一装备/武器/技能容量校验。商人不出售直接增加人物等级、经验或永久行动次数的物品。

出现以安全事件为前置，且是玩家实地可走到的摊点：第二章 C2-13 后的街口；第三章 C3-08 后的内湾安全边；第四章 C4-10 后的前院；第五章 C5-13 后的后院；第六章 C6-12 后的前庭接应处；第七章 C7-05 前的休整石阶。只有一个商人身份与一份全局库存，跨章看到的货架不会复制货物。终战开打后按原整备规则离场，不能凭打开货架重置阶段资源。

库存只随批次首次解锁增加，购买减少；休息、读档、跨章往返、再次战胜已结算遭遇都不刷新。库存条目键采用“商人 ID＋商品 ID＋批次版本”，交易保存买前数量、买后数量、单价版本、数量、扣款与取得物；全档重放核对。钱不足、库存不足、物品无效或写档失败时全部不变。展示价格和实际扣款必须来自同一表。

无等级迁移必须先解除银钱对 XP 的隐含耦合：将目前普通 59、Boss 105、终局分支 115 银钱写成明确奖励配置，首版保留经济基线；不要把删掉 XP 误做成胜利只给 25 银钱。现有旧交易/战果按旧版本规则验证，转换时保留合法余额与已购买库存，不重发历史奖励。第二章主线 3 场普通＋1 场 Boss 加初始 120，共有 402 银钱；这是预算计算，不是平衡已通过。零购物、零可选掉落也必须能推进主线。

## 8. 掉落、商店与存档的共同事务

掉落配置按敌类定义差异，但奖励在**正式遭遇首次胜利事务**统一结算。语义是“本场战斗后回收/记录”，不是每次敌人 HP 归零就生成实体掉落。初始敌、召回纸兵、重接锁片不得多次触发；背岸将本体倒下使纸兵散去仍可正常结算，不鼓励无意义清光杂兵。

关键字段须包含奖励版本、正式遭遇/来源场次、真实持久战斗 ID、敌类、物品/数量、首次领取键。普通敌特殊回收以“周目＋敌类＋奖励版本”唯一，Boss 与阶段以“周目＋正式场次＋奖励版本”唯一。选择先暂缓后再战时，按当时真实胜利来源结算，不能把未来胜利回填旧事件。已成功保存的阶段不再次发银钱、装备或回收记录。

统一处理次序：校验旧持久基线 → 复制候选 → 验真实胜利或服务位置/前置 → 算奖励/价格/库存 → 更新领取与交易记录 → 全档重放校验 → 临时写档并读回 → 原子替换 → 刷新 UI。失败保留余额、装备、掉落、库存和当前位置；不能先弹“得到物品”再报告写档失败。

旧档迁移不得根据“某章已开放”推断所有旧敌都已打或物品都已领。旧正式胜利记录能够证明的，记成历史已结算、不补发新增经济奖励；新只读机制页可以标“历史战果可回顾”，不能伪造曾拾得新物品。未知版本和损坏档报错保留，独立RPG/旧卡牌档不迁移。无人物等级的迁移、银钱重放和成长规则必须由同一版本契约连接，不能只删除 UI 等级文本。

## 9. 实施优先级、验收与边界

| 优先级 | 独立可交付模块 | 完成条件 |
|---|---|---|
| P0 | 后章首次胜利奖励/物证账本；银钱显式配置 | 26 场真实战果来源可追溯；重试/暂缓/读档/召回不增发；旧余额不变；不依赖 XP |
| P1 | C2 水口可逆实验，C3 修渡局部状态与现场复验 | 操作有可见因果、合法重置与原文衔接；保存/返场还原；零购物可完成；不自动发救援 flag |
| P2 | 神秘商人首见与共享限量库存 | 身份独立、位置安全、同一货架跨章一致；钱不足/库存不足/存档失败均无扣款；原NPC批准店铺不改台词 |
| P3 | C6 双线、停阵复验、漂木、后巷，继而 C4/C5 组合 | 按原分支实地发生；未救/待醒/待渡区分；控制实销无替代来源；完成后交通变化可见 |
| 后续专项 | 任务簿与解谜小游戏系统 | 仅按另文规划，当前不实现任何任务运行时、任务 UI 或领取接口 |

关卡与战斗验收：每章有与前章不同的主操作和一个不被奖励面板打断的余波段；关键敌方意图、免疫、反射和窗口在输入前可读；无人物等级下至少验证六身份合法三人组合与武器/容量合法构筑，不用统一高等级夹具掩盖数值问题。速度决定行动顺序，行动预测与真实结算一致；道具、技能卡增减属性的结果需在预览中可解释。

内容与事务验收：批准对白源哈希保持；不添加新章/新结局门槛；第一章旧装备掉落不变；零银钱、无特殊回收、全部支线晚做时主线仍有合法路径。C5 隔离保留两人待醒，C6 可补办；C7-S01 不改变结局。每种奖励和每笔交易有唯一可重放来源；重复提交、崩溃恢复、跨章往返、存档损坏和未知版本分别测试。

测试从隔离 Python 入口开始，先核验引擎真实 `user://`，再执行状态事务、真实战斗指令、跨进程续档；地图道路、位置返场、可见反馈、键鼠/手柄/字幕与缩放单列 GUI 验收。新增资源后才需导入/发布哈希门禁。本次仅研究和编写文档，未运行 Godot、导入、视频生成或发布，不声称人工全章通关。
