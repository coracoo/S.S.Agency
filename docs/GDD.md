# 《逢魔退治帖》GDD v5：无等级构筑与七章策略体验

> 2026-10-08：用户十一项持续目标取代旧v4成长与卡组方案。以下是目标设计，具体实现程度以[持续进度](strategy-overhaul-progress.md)为准。

当前正式入口仍为七章三维探索＋三人回合制队伍。人物没有等级成长，固定身份与专长保留，通过武器、护具、器物、道具和可穿戴技能卡形成构筑。用户已确认技能允许跨职业，但受武器类型与装配容量限制；速度影响行动顺序。

当前完整设计以[无等级策略改造设计](superpowers/specs/2026-10-08-strategy-overhaul-design.md)为准，按[实施计划](superpowers/plans/2026-10-08-strategy-overhaul.md)推进。七章剧情事实仍以[七章说明](campaign/seven-chapters.md)及批准导出源为准。

| 设计支柱 | 目标体验与验收方向 |
|---|---|
| 战前构筑 | 4主动技能位、2被动/器物位；拥有、武器和容量合法才可装配，属性变化可预览；初始容量与平衡须实战校准 |
| 策略战斗 | 可读敌意图、速度轮序、控制/净化/掩护取舍，难度来自机制组合与资源限制 |
| 七章关卡 | 调查、地图机关、路线风险、救援、危机、安静余波交替，避免固定对话—战斗循环 |
| 收集与交易 | 神秘商人、持久库存、装备/技能卡成长，敌种特殊掉落与剧情物证明确分离和关联 |
| 视觉演出 | 全技能变体真实事件驱动；全视频动作审计/抠图优化；敌人攻击与死亡闪烁消失 |
| 探索操作 | WASD移动、E交互、空格跳跃、Shift跑步；地图及模态输入边界一致 |
| 解谜任务系统 | 所有任务均以解谜小游戏设计；本阶段只规划，不实施任务系统 |

没有人物等级不等于抹去角色差异：身份基础值与专长决定擅长方向，装备、卡牌和道具承担成长；原等级解锁技法须转换为可追溯的技能/装备来源，不能只隐藏Lv文案。正式保存规则、旧档合法迁移、数值预览和回放必须同步。

当前正式schema3已实际去除人物等级/XP，装配与旧档备份迁移已接入。主动卡4位/容量10，被动卡2位/容量4；收藏可供多人准备，实物装备按全队持有数量计数。主动卡决定可用技能，被动卡承担属性增减与技能代价取舍。焰华两套主动配置共享身体属性、装备与被动，切形不增加行动次数或恢复资源。身份专长仍属于原人物，借用技能不能复制另一个人的专长。

现有24技能/28美术变体已启用。原美术、源视频、旧PNG与批准对白持续保护；新增抠图版本先独立保存并目检，再登记替换运行引用。神秘商人已经实地接入：六件装备与四张被动卡按章解锁，每种本周目限一件，跨章和读档不补货，第一场终战胜利后离场。普通药品商店继续独立使用银钱。

21类敌物已接入首次胜利回收与永久回收册：材料作为不可消耗的藏品和调查对照，来源由已提交战果推导，重复交付不重发。34组调查联系只在对应批准事件完成后开放；原同源镜屑、实销等关键物仍由原剧情取得。最早GDD提供环境观察/回收理念，具体材料名与联系属于本轮新设计。

六个实地机关已落地：水口可逆复验、第三章与第六章共享修渡、双线拆接、不同同伴停阵复验、漂木与担架实走、后巷战前遮镜及战后拆镜/接应。操作在批准的成功叙述之前发生，完成后续播；已取实销、已拆远镜和已清通路不会靠读档复原。机关只提交实际状态，原剧情flags仍由原场次完成产生；任务系统仍未实现。

无等级自然补给平衡、第四/五章进一步的场景组合和全程体验验收仍待完成。当前连续终战对照中，三类测试构筑携带不超过300银钱的补给仍在第二阶段败北；局部单场获胜不能代替三阶段资源平衡。原敌人数值基线会根据机制、装备成长与自然资源测试继续调整。

参考借鉴[D&D官方施法准备](https://www.dndbeyond.com/sources/dnd/br-2024/spells/)和[魔法物品装配](https://www.dndbeyond.com/sources/dnd/br-2024/magic-items/)的有限选择思路；本项目的无等级数值、技能卡容量和轮序是独立设计。
