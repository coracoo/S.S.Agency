# 《逢魔退治帖》GDD v5：无等级构筑与七章策略体验

> 2026-10-08：用户十一项持续目标取代旧v4成长与卡组方案。以下是目标设计，具体实现程度以[持续进度](strategy-overhaul-progress.md)为准。

当前正式入口仍为七章三维探索＋三人回合制队伍。人物没有等级成长，固定身份与专长保留，通过武器、护具、器物、道具和可穿戴技能卡形成构筑。用户在第一章试玩后已确认**所有技能完全按角色锁定**，取代原跨职业方案；专属卡额外受形态、武器类型与装配容量限制，速度影响行动顺序。

基础设计见[无等级策略改造设计](superpowers/specs/2026-10-08-strategy-overhaul-design.md)，按[实施计划](superpowers/plans/2026-10-08-strategy-overhaul.md)推进；角色归属和首章体验的最新修订以[试玩反馈改造](verification/2026-10-08-playtest-remediation.md)为准。七章剧情事实仍以[七章说明](campaign/seven-chapters.md)及批准导出源为准。

| 设计支柱 | 目标体验与验收方向 |
|---|---|
| 战前构筑 | 4主动技能位、2被动/器物位；拥有、武器和容量合法才可装配，属性变化可预览；初始容量与平衡须实战校准 |
| 策略战斗 | 可读敌意图、速度轮序、控制/净化/掩护取舍，难度来自机制组合与资源限制 |
| 七章关卡 | 调查、地图机关、路线风险、救援、危机、安静余波交替，避免固定对话—战斗循环 |
| 收集与交易 | 神秘商人、持久库存、装备/技能卡成长，敌种特殊掉落与剧情物证明确分离和关联 |
| 视觉演出 | 全技能变体真实事件驱动；全视频动作审计/抠图优化；敌人攻击与死亡闪烁消失 |
| 探索操作 | WASD移动、E交互、空格跳跃、Shift跑步；地图及模态输入边界一致 |
| 解谜任务系统 | 所有任务均以解谜小游戏设计；本阶段只规划，不实施任务系统 |

没有人物等级不等于抹去角色差异：身份基础值与专长决定擅长方向，装备、卡牌和道具承担成长；原等级解锁技法须转换为可追溯的技能/装备来源，不能只隐藏Lv文案。正式保存规则、旧档合法迁移、数值预览和回放必须同步。

当前正式schema3已实际去除人物等级/XP，装配与旧档备份迁移已接入。主动卡4位/容量10，被动卡2位/容量4；收藏只供归属人物准备且不消耗，实物装备按全队持有数量计数。`build.version=2`下普通人物6主动候选/3专属被动，焰华剑法各6候选/共享自己的3被动，总计42主动卡/18被动；原式与同招式变式互斥。主动卡决定招式及费用/效果取舍，装备和被动卡承担属性增减与技能修正。装配页支持武器与卡片共同编辑、一次保存；非法中间草稿不落盘，取消同时放弃两者。详情、预览与实战复用派生，`SKILL_DERIVATION_VERSION=3`纳入回放。焰华两形态共享身体属性、装备与本人被动，切形不增加行动次数或恢复资源。旧跨角色装配严格校验备份后卸下外人物卡，收藏保留，当前血蓝不回满。以上新规则尚待测试。

现有24技能/28美术变体已启用。原美术、源视频、旧PNG与批准对白持续保护；新增抠图版本先独立保存并目检，再登记替换运行引用。神秘商人已经实地接入：十三件装备与四张被动卡按章解锁，每种本周目限一件，跨章和读档不补货，第一场终战胜利后离场。普通药品商店继续独立使用银钱。新增七件装备提供法盾混合、快弓、重刃、防护、灵力储备与速度取舍，使用独立扩展表；旧十商品的ID、价格和历史交易不改。新装备与货架扩展尚待测试。

21类敌物已接入首次胜利回收与永久回收册：材料作为不可消耗的藏品和调查对照，来源由已提交战果推导，重复交付不重发。34组调查联系只在对应批准事件完成后开放；原同源镜屑、实销等关键物仍由原剧情取得。最早GDD提供环境观察/回收理念，具体材料名与联系属于本轮新设计。

六个实地机关已落地：水口可逆复验、第三章与第六章共享修渡、双线拆接、不同同伴停阵复验、漂木与担架实走、后巷战前遮镜及战后拆镜/接应。操作在批准的成功叙述之前发生，完成后续播；已取实销、已拆远镜和已清通路不会靠读档复原。机关只提交实际状态，原剧情flags仍由原场次完成产生；任务系统仍未实现。

第四、五章新增镜廊系绳/遮镜/接灯/支缝通行，以及单床查线/隔床/断扣/石院交接/撤防复测，现合计八机关；新两组已写入规则、分段对白、地图表现与存档扩展，尚未测试。新版为schema3/progression_version=4、机关version=2，六机关旧档原操作历史保持，只迁移新增两组的已完成事实。

终战第一阶段首胜后，阶段间免费休息与普通采购关闭，携带药物、合法装配和原剧情补救路线仍可使用；原败北短聊开放对应阶段重新整备，阶段胜利后继续承接剩余资源。最终胜利解除限制。模型、队伍菜单、地图与商铺共享规则；已实现，未验证。

战斗新增“战术一览”（T/右上角按钮），直接展示意图、双防、反射、打断窗口和前置目标保护；当前轮速读取已公布轮序，下轮按当前存活/状态作条件推演，和实战共用排序。查看不消耗行动，不清除已选指令。该界面尚未运行验收。

固定敌值现为r4候选：第一章五夜分化双防、速度和物术压力，焰华基底提高剑形输出；C2–C6保留r3的纸兵/灯影双防、Boss生命与左右锁片速度分工，C7沿用r2三阶段值。详见[数值与构筑](campaign/strategy-balance.md)。首章未新增遭遇或改变批准剧情；自然七章资源和全程体验仍待其他模型验证。终章固定敌值r2早先观察中，两类构筑过前两阶段后败于最终阶段，控制队仍败于第二阶段；不能据此宣称平衡完成。按用户要求，本轮仅完成改造并交付[测试方案](verification/2026-10-08-playtest-remediation.md)，不执行新测试。
