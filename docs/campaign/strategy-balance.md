# 无等级七章策略数值与构筑（r4候选）

2026-10-08。本文对应生产配置 `data/rpg/strategy_encounters.json` 的 `balance_revision=4`，以及角色专属卡、新装备与终战补给规则。**按用户要求仅完成实现，不执行测试；这些是设计值，不是平衡验收结果。** 首章试玩后修订及完整验收见[反馈处理](../verification/2026-10-08-playtest-remediation.md)。

## 难度来源

固定身份基底不再获得旧L6—L10的属性增长，后章不能原样依赖旧等级的等比堆血。r3对后章的双防/Boss处理保留；r4只追加首章敌人速度、物术压力和双防修订，全部章节仍保留已登记的技能、出场数量及剧情顺序。玩家应看目标、看出手时机、看资源，而不只是重复最高系数技能。

战术一览通过战斗右上角按钮或T打开，展示真实意图、反射、前置目标保护、当前打断窗口和本轮顺序；下轮速度为保持当前存活/状态的条件推演。实际排序与推演共用 `turn_order.gd`，推演在副本上调用同一状态时钟。未命中的未来行动、伤亡、召回、净化和Boss换阶段均不预言。

## 构筑与经济预算

保持4主动/容量10、2被动/容量4。新武器并非所有标签通吃：护灯符盾只有法器与盾标签；逐影强弓只有弓；破阵重刃只有刀剑。新护具和饰物带负面词条，速度决定先后而非多得一次行动。

后章初始120文，普通胜利59文、Boss105文，最终方案战115文。按无可选战斗的主线路径静态相加，进入终战前：稳灯路线约1117文累计收入，隔离路线约1058文；这只是配置总和，尚未扣沿途花费，不能当成玩家到终章的实际余额。第一章装备、原固定补给与支线收益另列，不能假定每局额外路线全部可得。

示例预算取舍：护灯符盾220、引流法衣200、蓄息念珠160，共580文，侧重术法与打断续航；叠符护衣180、逐影强弓210、疾行绳结150，共540文，侧重先手输出和保护。剩余银钱要与日用药18/22/45文及被动卡竞争。这些是购买组合示例，不是通关推荐或已测最优解。

装备增加上限不会即时补满，反复穿脱不能回HP/MP。技能只供归属人物准备，焰华两形态共享本人被动；实物装备受全队持有数量限制。商人库存全周目共享，原十商品与价格保持；已收录被动卡无需重复购买，购买前展示归属人物。

详见[测试交接方案](../verification/2026-10-08-strategy-handoff-plan.md)。必须分开记录：零购物、日用药、可选构筑；默认均衡、纯物理、无治疗及保护/快攻/控制；正常连胜与败北整备路线。不能以单队满资源或直接改快照证明平衡。

早先r2三组自动观察全部未完成连续三阶段，这是已知历史结果；不随着r3文件修改而变成通过。下轮若结果仍显示主要靠拖长战斗消耗，而不是正确机制选择获得收益，应进一步调低无意义消耗或调整公开窗口，不靠补无限药或削弱所有敌人攻击凑过关。
