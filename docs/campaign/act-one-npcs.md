# 第一幕人物交谈

2026-10-05新增，连续寺域内可见全身、靠近交谈的独立普通人和未出战同伴。原52个探索/结案节点、奖励、战斗成员资源、世界存档schema不变。

## 人物与站位

- 守山人·老梁：山门前庭侧边 `(14, 2.89, 3)`，身高172cm，负责进山和回程路引。
- 扫庭人·阿诚：前庭北侧 `(21, 2.89, -3.1)`，身高176cm，负责檐下、纸棺庭和镜殿方向的环境短句。
- 岑照：前庭集结处 `(17.6, 2.89, 5.6)`，186cm，只有 `p_guard` 未出战时出现。
- 薄荷：前庭集结处 `(19.9, 2.89, 5.6)`，158cm，只有 `p_ranger` 未出战时出现。
- 清明：前庭集结处 `(22, 2.89, 6.5)`，166cm，只有 `p_controller` 未出战时出现。

默认凛音/薄荷/岑照队伍下有老梁、阿诚和清明三人。两个居民始终可见；同伴是否出场按实际队伍actor ID派生，不另外保存状态。仅设置五夜不同的路引和所见所闻，不增经济、交易、奖励或支线。

原故事明确使用“神社”，老祭主是棺守。新人物采用普通守山人、扫庭人称谓，不新设僧职或祭主，也不宣称常住神社。小夜仍为剧情亡灵，前三夜的旁白不提前交代她和顾家的关系，棺守仍由原战斗/主线处理。

## 代码接口

`res://scripts/campaign/act_one_npcs.gd`

- `definitions(night_id: int, party: Array = []) -> Array[Dictionary]`：每项有独立 `npc:*` ID、`kind: npc`、姓名、身体原点坐标、`radius: 2.1`、当夜文字、身份/身高与来源。无效夜次返回空数组。返回值互不污染。
- `build(night_id, party) -> Node3D`：创建 `ActOneNPCs`。所有人物为纯视觉 `AnimatedSprite3D`，无物理碰撞体和可攻击对象。
- `refresh_night(night_id, party)`：复用还在场的人物，移除出战同伴，补回新退出队伍的同伴，并刷新对白。换夜和关闭编队面板后由舞台同步调用。
- `portrait(npc_id) -> Dictionary`：居民只返回独立的 `*_half.png` 半身对话图；同伴复用 `IdentityPortraits` 的主线统一上身取景。绝不返回地图全身首帧；不存在时返回明确的空肖像。

无需给交谈写入事件标志。正文由 `night_id` 稳定派生，重新加载同一夜文字相同。舞台交谈使用自己的输入锁与结束回调，不借用主线事件完成接口。

## 素材与身高

两居民先独立生成身份图，再根据用户“统一角色画风、所有人物立绘都是半身”的纠正，用内置image_gen分别重绘专用半身与匹配的地图全身。画风参考来自当前认可的凛音/岑照高清源与正式上身取景；原主角图没有重绘。没有把多人图裁成单人，没有复用敌图或给原角色换名。完整PNG、SHA256、prompt、头顶/脚底参考在 `assets/chars/npcs/act_one/asset_manifest.json`。当前启用的地图图是 `liang_world.png` / `acheng_world.png`，对话图是 `liang_half.png` / `acheng_half.png`。最初的水彩写实版保留在原路径但不再使用。原图留有透明像素，场景通过alpha scissor 0.5保留清晰轮廓。半身图肩外与头侧六点alpha均为0。静态居民使用单帧idle，无行走或战斗动画。

三同伴只读取原高清完整idle。已逐张检查头发、衣摆和脚都完整，manifest的layers均为空，不缺少分层部件。身高与脚锚使用现有 `CharacterStature`。两居民身高为本轮呈现配置，不声称来自旧设定；排除透明画布留白和手持道具测量身体高度。所有人物脚底原点与地面2.89m对齐。

## 验证

入口先由隔离runner核验引擎真实 `user://`，然后运行：

```sh
python3 tools/campaign/run_act_one_checks.py --script res://tools/campaign/test_act_one_npcs.gd
```

独立NPC检查覆盖：

- 五夜短句、同夜重载稳定、无前三夜关键身份剧透，固定旁白不判断水钵是否已调查
- 默认队伍过滤、换队立刻增删实体、再次刷新不重复创建
- 每一角色的原PNG真实不透明头顶与鞋底，固定比例实际身高和零脚底偏移
- 五人真实地面射线、站位胶囊不与墙/植床/石灯重叠、至少两侧可近身
- 没有NPC碰撞/攻击实体，使用3D深度测试
- 居民专用半身与地图全身分离，同伴只走统一上身取景，未知id清空肖像
- 原探索/结案文件hash未被查询、生成和换夜改动

此检查不替代正式舞台的E键距离、输入锁、对白结束、换队和存读流程验收。实际场景截图与这些舞台集成由对应验证脚本另行记录。
