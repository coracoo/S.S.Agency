# 第一幕连续寺域几何

`scripts/campaign/act_one_geometry.gd` 是可编辑的程序化场景原稿；`build(config)` 返回 `ChapterGeometry`，`update_visibility(position, delta, camera)` 只裁美术与灯光，地面、门柱、侧墙与边界物理始终存在；旧单参数调用兼容。近景树按真实相机投影覆盖人物时，在约0.18秒内渐隐到每层1.2%（多层叶片叠加后仍保持人物可读），离开后带0.35米边缘滞回逐渐恢复原材质。使用Compatibility支持的每实例材质alpha，不改共享材质或碰撞。地面矩形与夜次偏移由 `act_one_layout.gd` 统一登记。

## 原资产使用

- 首夜 `act01_approach.glb` 原位，保留 0..2.89 米上山坡与水钵。不存在其 Blender 原稿，不声称拥有。
- 第二夜使用 `night02_corridor_hd2d.glb` 的 MidCorridor 原中景；不叠加 base，也不把原摄影棚 NearFrame、OuterForecourt、DistantGate、SideVeranda 整套复制进连续世界。
- 第三、四、五夜分别原位加载各自 GLB 后加共享偏移，仅去掉旧独立场景用于填充镜头的外部地景。各资产的 `source/` 原 Blender 文件和生成脚本完全保留。
- 新基础、低压顶、木构复用回廊原石材、木材和灰泥纹理；五张PNG以显式preload声明，支持resources导出的依赖收集。原瓦和和纸仍由真实建筑保留。新山门与庭灯、杉木复用首夜网格，不是纯色替代物。
- 庭院仅主通路铺石，其他区域为仍可自由行走的原土纹地面；石路和泥土的物理面统一为2.89米。`act_one_stone_library.gd`把原UpperLanding拆成16块独石，以原0.63×0.73米比例错缝铺装，边缘允许少许伸入土面。
- 新外圈为连续起伏山土与分组杉林，原岩组按网格连通块拆石后逐块按当地高程接地，不把随山阶升高的原石组整套平移造成浮石。植区与地面共用原土纹的世界UV，低起伏接入土地，没有椭圆圆盘或整块纯绿剪片。
- 镜殿两侧纯美术整墙替换为保留原材质的后短墙、门楣和真实通口；前粗柱补接檐托梁，庭后神木移到右侧独立土庭。本殿保留神木原位置，以两侧开放梁框替代正中遮住树洞的横梁/中柱；原整块石台在根区留出真实种植开口，坑内土面与根底相接，周围原石收口。原木柱、棺、柜、后墙、山门均有对应碰撞。

## 可走连接

原坡口 → 山门 → 前庭 → 回廊／中央庭院 → 北侧镜殿、南侧纸棺庭 → 本殿；两侧路径可组成双向返程环路。物理不由故事夜次开关，也不调用场景切换。新地基按庭院与侧路分块，不铺覆盖整个全图边界的巨板。

## 自动验证

`python3 tools/campaign/run_act_one_geometry_checks.py`

先独立启动 Godot 验证真实 user 目录隔离，再验证：

- 18 段环路正反连续胶囊扫掠，沿线每 0.4 米检测地面
- 山门真柱不可穿过、各区原资产与随位移灯光存在
- 距离裁剪后远端碰撞依然有效
- 总物理体数量受限，外边界按矩形并集的端点分割
- 原石比例、植床材质、独石贴地、后域神木视口和纸棺庭前景遮挡的回归契约
- 纸棺侧径`(49.19,2.89,4.86)`真实移动帧遮挡回归：进入渐隐、边界微动稳定、离开恢复原材质、碰撞数量恒定
- `[20,2.89,4]` 原庭院返场点胶囊不重叠，x20纵向主路持续畅通（扫掠之外单独检测起点重叠）
- 与正式角色同尺寸、同速度、同坡度与贴地参数的 CharacterBody3D 实际上山、进庭、下山往返

第三、四、五夜的原棺底按真实包围盒下降约2–3厘米接地，底面局部暗部按棺体尺寸制作；镜盘提示灯缩小到镜面附近。新土院网格按原建筑边界挖空，避免比新公共碰撞面略低的木板被泥土穿插。

这套无头检查不替代真实角色、正式相机和美术画面的引擎目检。舞台采图由集成任务负责。
