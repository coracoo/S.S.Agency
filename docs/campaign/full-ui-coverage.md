# 正式全流程 UI 覆盖

基线：已批准的分层生图菜单 f824882，加上用户主线 ecbbdf5 的天幕、冷色补光与雾。隔离分支仅整合 UI，不改角色图片、动画帧、故事正文、战斗数值或装备外观系统。

## 本轮覆盖

1. 标题：新游戏、继续、覆盖确认、取消加载、读档失败。
2. 探索：紧凑 HUD、调查提示、地图、线索/守灯确认、保存失败重试、返回标题确认。
3. 故事：姓名、长对白、快进/继续、长选项；保留真实角色与半身图来源。
4. 整备：沿用已验收的菜单、队伍、行囊、装备和真实内框留白。
5. 战斗：队员/敌人信息、血蓝、状态、目标选择、技能/道具、行动预览、日志、取消、返回确认、胜败/重试/返场。
6. 结尾：送行、续监和缺少完成记录状态。

所有可视面板、按钮和血蓝条优先复用已批准的生图 PNG；动态文字、数字和实际地图拓扑继续由游戏数据驱动。不能用一张概念图替代实际交互，不制造不存在的地图、装备、商店或奖励。

## 验收

- 修改前先写失败的纹理/边框安全区和交互用例。
- 隔离 user 目录测试真实模型、读档/写失败、取消、重复操作和输入锁。
- 1920×1080、1280×720、1180×812 实际 Godot 渲染；覆盖各页及失败/确认状态。
- 检查实际字形与装饰内金线的距离，不能仅检查 Control 矩形；保留图形证据与像素检测。
- 核验发布资源与原 PNG 依赖闭包、全 RPG 回归、正式场景契约。
- 不把截图夹具或自动模型通关写成用户等价人工完整通关。未覆盖部分明确列出。

## 当前验证边界

主验证引擎为 Godot 4.7.2。全 RPG 门禁及发布依赖检查按本轮最终记录执行。4.6.3 的标题取消加载测试行为断言通过，但退出时存在已用未改标题复现的44个 DummyTexture RID /异步准备协程泄漏；本轮没有改写人物资源生命周期，不能标成该引擎全通过。历史试玩缺失视差图仍是旧警告。

图形证据包含探索12张、故事33张、战斗30张，覆盖三个窗口比例。战斗终局/四敌/长状态和部分保存错误使用明确标记的隔离显示夹具；群体预览先通过真实行动推进与合法目标断言。它们不代表人工打完整五夜。新增全屏窗口设置、音频设置和装备换装系统不在既有正式UI的本轮实现范围。
