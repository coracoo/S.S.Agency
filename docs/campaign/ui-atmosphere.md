# UI与寺域氛围精修

> WIP开发检查点：用户要求先push本地检查，整体画面风格尚未最终验收。

本轮沿用连续寺域与现有RPG流程，只改变表现与输入可用性。作品名《逢魔退治帖》保留；正式标题只有开始新游戏、继续游戏、退出游戏。旧v3的“新的委托”未接入此入口。正式战斗标题用“遭遇 · 夜巡异象”，胜利用“异象平息”。

## 统一的界面层级

- 墨青/烟墨底、米白主字、灰绿次级；暗朱用于主要动作，赭金用于焦点与少量提示。
- 探索只常驻地图与暂停；景深/返回标题收进暂停，目标显示下一调查项，移动教学渐隐；对白整层HUD退场。
- 对白保留全部半身原画；姓名成为同套面板内的小标识，去掉亮黄纸与厚黑刷框。
- 编队保留六身份选三人、双形态和原道具规则；选中与禁用在文字和边线两方面区分。
- 战斗状态卡避开人物头部，HP条固定细线并与MP分行；长状态仍可滚动。
- 总览以实际可走区域合并轮廓与连接路线绘制，不提供传送。
- 标题、舞台模态与战斗返回确认框有真实键盘焦点；确认框的Tab及四方向均限制在本框内，关闭恢复此前焦点。按住E、重复确认和关闭后持续移动不会穿透。

## 灯光和场景

连续世界显式固定Compatibility渲染。有限范围月光保留真实树柱、屋檐方向投影；反向法线已修，地面/木板只接收阴影、不作无意义自投影，双面素材使用反向剔面消除岩瓦条纹。阴影不能以大黑椭圆代替。相机空间景深采用单pass十三点错位采样，开关在本次会话跨战斗/舞台保留。

原参道木石瓦纸材质继续复用。前庭为枯木根边半埋旧碑、败花、小骨片及少量干褐红旧痕；北路灯边是败花与破陶盏；南界外是隐约碎碑骨片。外林少数枯树改变轮廓，路缘有轻微色差/缺石/低草，主路线和碰撞不变。细枝花瓣按材质合批。

主角恢复原参道已使用的人物场景受光与逐脚接地；驻场NPC使用同一受光shader并随待机换帧更新纹理。角色原PNG、身高、对白半身和战斗立绘没有重画。标题单独使用轻量原参道/山林/雾背景，不装载全寺域、人物或会话。

## 运行与版本

代码在官方4.6.3与4.7.2的Linux环境验证；目标用户Windows已报告使用4.7.2，不能把Linux测试当作Windows或其显卡性能结论。

直接从项目标题启动。Windows可双击`play.bat`或`启动游戏.bat`，工程位置以脚本所在目录为准；优先使用`GODOT_BIN`，否则查找旁边及既有Godot目录的4.7.2、PATH，最后保留4.6.3回退。启动器不下载或安装引擎。Windows批处理目前只有静态契约检查。

原PCK发布工具仍保留官方4.6.3版本门禁，本轮没有把4.7.2源码运行测试冒称4.7.2发包认证。
